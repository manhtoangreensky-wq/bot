# Chat AI Tiers - TOAN AAS

## Philosophy

TOAN AAS should not sell chat by tiny token math. Pricing is based on:

- answer intelligence
- model level
- content weight
- operational value
- provider cost and refund risk

## Normal Chat

- User sends plain text to the bot.
- Uses fast/economy AI routing.
- Best for quick questions, captions, content edits, and fast ideas.
- Trial accounts use daily fair-use.
- Not intended for deep strategy or long documents.

## Chat Pro

- Command: `/chat_pro`
- Price starts at 20 Xu.
- Best for deeper business analysis, code/debug help, content strategy, prompt design, and structured plans.
- Refunds Xu when AI fails after charge.

## Chat Deep

- Command example: `/chat_pro tier=deep ...`
- Price starts at 50 Xu.
- Best for strategy, systems, long content, and senior-level analysis.
- Advanced provider names such as Claude Sonnet/Opus or Grok remain planned until configured.

## Pricing

| Tier | Price |
|---|---:|
| Normal | fair-use / existing normal chat flow |
| Pro | from 20 Xu |
| Deep | from 50 Xu |
| Long content | +20 Xu / content unit |
| Maximum | 200 Xu |

## Safety

- Do not expose API keys.
- Do not call providers that are not configured.
- If Chat Pro fails after Xu is charged, refund Xu.
- Do not guarantee revenue outcomes.
