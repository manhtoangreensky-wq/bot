## AI CSKH And Sales Logic

- AI CSKH can handle thousands of conversations at the same time while keeping consistent consultation quality.
- Product consultation should standardize power, capacity, features, warranty, usage scenario, price band, and buyer objections.
- The assistant classifies customer needs, routes customers to the right product group or human team, and records the reason for each route.
- Sales logic should suggest products, bundles, upgrades, and upsells based on customer intent, budget, use case, urgency, and likely objections.
- Conversation data should be stored and reused for follow-up, remarketing, product education, FAQ improvement, and future video/content planning.

## One-Image Commercial Workflow

- TOAN AAS can create a commercial/video direction from one product image when the user has rights to use that image.
- The output should create a new commercial concept, not copy another creator's original content.
- Standard pipeline: trend -> hook -> script -> storyboard -> image prompt -> image/video -> voice/music/subtitle -> CTA.
- Each storyboard should keep a consistent visual canon: subject, product, brand style, color palette, location style, lighting, camera style, character consistency, product consistency, and forbidden elements.
- If one scene fails, retry that scene only and keep the rest of the storyboard, canon, and order intact.
