# TOAN AAS Beta Sales Package

Date: 2026-06-02

## Goal

Sell to the first 3-10 beta users to validate real demand, payment flow, and the Telegram workflow.

## Beta packages

## New user experience

- Tài khoản mới nhận 200 Xu trải nghiệm.
- Có thể thử 1 `/film` Basic trước khi nạp thêm.
- Sau đó chọn nạp 10k/50k/100k nếu muốn tiếp tục.

### Package 1 - Trial User - 10k

- 100 Xu.
- For testing the bot.
- Goal: user confirms the bot works and understands Xu.
- Suggested commands: `/profile`, `/naptien`, `/film`, `/help`.
- Optional controlled promo: if admin sends a private code, user runs `/promo <code>` before paying.
- `BETA50` test expectation: 10k package gives 100 Xu plus 50 Xu promo = 150 Xu total.

### Package 2 - Creator Start - 50k

- 500 Xu.
- For creating script/caption content regularly.
- Goal: user creates 5-10 content pieces.
- Suggested commands: `/film`, `/addlink`, `/calendar`.

### Package 3 - Affiliate Builder - 100k

- 1,050 Xu.
- For a 7-day affiliate content test.
- Goal: use `/film`, manual posting, `/performance_report`, and `/growth_ai`.
- Suggested commands: `/publish_done`, `/performance_add`, `/growth_ai`, `/campaign_report`.

## Do not promise

- No guaranteed revenue.
- No auto publish.
- No spam workflow.
- No deepfake/non-consent content.
- No bypassing platform rules.

## Correct promise

- Faster content creation.
- Clearer workflow.
- Manual tracking of posts and results.
- AI suggestions for improving hooks, captions, and CTA.
- Promo codes are limited beta bonuses, not permanent package price changes.
