# First Customer Beta Plan

Date: 2026-06-02

## First customer profile

- Affiliate sellers.
- TikTok/Facebook short-form content creators.
- Small shop owners.
- People who need captions/scripts quickly.
- New users testing AI automation in Telegram.

## Beta sales process

1. Send the website link.
2. Send the Telegram bot link.
3. Ask the user to run `/profile`.
4. Ask the user to run `/beta_offer`.
5. Ask the user to top up 10k or 50k through `/naptien`.
6. Ask the user to generate first content with `/film`.
7. User posts manually.
8. User records post with `/publish_done`.
9. User records metrics with `/performance_add`.
10. User runs `/growth_ai` after there is enough data.
11. Ask for feedback.

## Beta KPI

- 3-10 test users.
- At least 3 successful topups.
- No PayOS crediting errors.
- At least 10 `/film` runs.
- At least 3 `/growth_ai` runs.
- At least 3 user feedback notes.

## Stop conditions

- PayOS credits wrong amount.
- Duplicate webhook credits twice.
- User sees admin-only commands.
- Provider errors do not refund charged Xu.
