# Social OAuth Configuration Runbook

1. **Meta (Facebook/Instagram)**: Register Facebook App with Pages API and Instagram Graph permissions.
2. **Google (YouTube)**: Set up Google Cloud Console OAuth 2.0 Client ID for YouTube Data API.
3. **TikTok**: Apply for TikTok for Developers Content Posting API and complete Client Audit.
4. **Token Encryption**: Store tokens encrypted in SQLite WAL with zero plaintext exposure.
